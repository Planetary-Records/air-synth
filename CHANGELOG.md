# Changelog

## 0.1.0-alpha.2 - early alpha

- Adds twelve original starter sounds by name in BROWSE, with existing-note preservation and Undo.
- Opens a normal file dialog for the first SAVE and saves a user copy after choosing a starter sound.
- Keeps generated changes visible/auditionable before Apply and preserves the captured output setting.
- Separates saved sign-ins, retains unfinished registrations and explains permission/timeout failures.
- Lets unused helpers exit so updates can proceed, while preserving real active clients.
- Expands installation, first-session, host, troubleshooting and contributor guides, included offline.

- Adds the illustrated producer manual, local assistant setup, portable rack-creator skill and library contribution guidance.

## Earlier alpha testing

The initial private alpha established an empty first session, one-click starter sound, proposed-rack previews and local problem-report preparation. Earlier artifacts retain their own checks and limits; this candidate is not a replacement for their bytes or a stable release. Final version/download references are set when the qualified prerelease is published.
