# Security reports

Privately email [support@planetary.music](mailto:support@planetary.music) with subject **air security report**. This existing support/account-security contact is published in [Planetary's terms](https://planetary.music/legal/terms); no new mailbox or delivery guarantee is implied. Mail delivery was not tested during preparation.

Use the email route for private reports; do not post exploit details/credentials publicly. Ordinary bugs can use the bug template without sensitive details. No GitHub reporting form is advertised until it is enabled and tested for the eventual public repository. Mailbox delivery is a launch check, not a result of this source-only preparation.

Include affected version/commit, impact, reproduction and a minimal sanitized example. Exclude tokens, account storage and private projects. No response deadline, bounty or stable-version support window is promised.

Never execute an unknown PR on a maintainer's PC. See [CI safety](docs/development/public-ci-safety.md). Detach the development-PC runner before publication. History rewriting and credential rotation require separate owner authorization.
