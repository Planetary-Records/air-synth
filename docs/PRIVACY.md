# Instrument privacy and optional services

Manual synthesis, imported samples, saved kits, MIDI and sound recall work locally without an account/network service. Planetary services are optional. This describes inspected source behavior, not a completed network audit or a provider policy.

Explicit cloud AI requests use the native companion and OpenAI browser OAuth. Prompts, model choice, musical settings, sound/control/pattern context and explicitly selected peers' musical context can be sent to OpenAI. Do not include material you lack permission to share. Only the requesting instance applies changes. Provider account and usage terms apply separately. Sound generation remains experimental; a successful connection does not guarantee access for every account, and availability and limits may change. Manual controls and included sounds require no account.

Account/session data lives under `%LOCALAPPDATA%\AI Rack Synth\OAuthProbe`, preferences under `CompanionPreferences`. `session.bin` uses current-user Windows DPAPI and restricted file access. Sharing that folder is unsafe. The app does not use Codex account storage. air remembers accounts you sign in with; the Account menu lets you choose a saved account or add another. Account labels may include the email address supplied at sign-in. This alpha does not yet have an in-app option for removing a saved account. Close plugin/companion processes before deliberately removing local account storage; removing local files does not revoke the account's authorization.

Tile Array's optional Generate sends its prompt/fixed recipe to `http://127.0.0.1:8189`, a separately operated ComfyUI service. That service owns its model downloads, logs, temporary audio and retention. The plugin does not install/start it or attest which model ran. Kept audio is embedded in sound/project state. No weights are bundled. See [setup](user-guide/tile-array.md#optional-local-sample-generation).

Generation diagnostics under `%LOCALAPPDATA%\AI Rack Synth\Logs` record bounded status events: timestamps, process/runtime/session/request IDs, model identifiers, errors and durations. The inspected writer uses allowlisted fields rather than raw prompts, tokens or audio. Host crash reports and ComfyUI logs have separate contents. Review logs before sharing; paths, identifiers and musical context may be private without containing credentials.

Optional racks (the rack library). air includes its own racks and works without any connection. When you open the rack LIBRARY, and only then, air asks GitHub for the list of optional racks (a catalog file in the public repository Planetary-Records/air-rack-library and its published download counts), and if you choose to install or update a rack it downloads that rack's file from the same repository. These are ordinary web requests: GitHub sees your internet address and the program name "AIR Rack Library", as with any download. No account, project, sound, or audio is sent. Racks you install are kept on your computer, and air keeps working with them offline. If GitHub cannot be reached, the library says so and the built-in racks keep working. GitHub's own terms and privacy policy apply to those requests.

Problem reports (alpha). The ALPHA badge in the window opens a report form. The report is built on your computer and shown to you in full before anything is done with it; air itself sends nothing. You can copy it, save it to your Desktop, or open the feedback page in your browser, where only a report ID and the version number are placed in the page address. Technical details are optional (a tick box) and, when included, are the air version, Windows version, the name of your music program, the audio settings in use, whether the last session ended normally, and the last lines of air's own diagnostic log with your user name and computer name hidden. Your sounds, projects, audio, prompts and account details are not included. Your email address is included only if you type it into the form.

While it runs, air keeps one small marker file under %LOCALAPPDATA%\AI Rack Synth\Sessions so that it can notice, the next time, that a session ended unexpectedly and offer to prepare a report. The file holds a process number and start time, stays on your computer, and is removed on a normal exit.

Planetary's website and Buy Me a Coffee are separate services. Planetary's [terms](https://planetary.music/legal/terms) and [privacy policy](https://planetary.music/legal/privacy) describe its sites and creator services; they do not specifically document this instrument's OpenAI/local generation. This instrument note supplies that distinction. Privacy questions can use the website's published address, [privacy@planetary.music](mailto:privacy@planetary.music). Using the instrument does not imply consent to upload diagnostic attachments.
