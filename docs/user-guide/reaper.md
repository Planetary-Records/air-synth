# air in Reaper on Windows

[Install air](install.md), then open Reaper. This is setup guidance; human testing of the air alpha in Reaper remains unfinished.

1. Choose **Insert → Virtual instrument on new track…**.
2. Search the instrument list for **air** and choose its VST3 instrument entry. Reaper creates the track and opens the instrument.
3. In air, press **Start with a sound** if empty, then choose **External MIDI**.
4. Add a short MIDI item to that track, or drag an existing MIDI file onto it, and press Play. For a controller, set the track's MIDI input, arm it and enable input monitoring.
5. Save the Reaper project. [First session](getting-started.md) covers sound files, patterns and optional generation.

If air is missing, check Reaper's VST plug-in settings and rescan the shared VST3 location. Reaper's [official user guide](https://www.reaper.fm/userguide.php), under “Recording With a Virtual Instrument,” covers the instrument-track workflow.
