# air in FL Studio on Windows

[Install air](install.md), then open FL Studio. This is setup guidance; human testing of the air alpha in FL Studio remains unfinished.

1. Open **Options → File settings → Manage plugins**. In Plugin Manager, use **Find installed plugins** with **Verify plugins** enabled.
2. Add **air** as an instrument using the Channel Rack's **+ / More plugins** list. Newly scanned instruments can also appear under **Plugin database → Installed → Generators**.
3. Open air, press **Start with a sound** if empty, and choose **External MIDI**.
4. Add notes to that channel's Piano roll and play the pattern. Check the selected channel, mixer routing and output if it is silent.
5. Save the FL Studio project. [First session](getting-started.md) covers sound files, air's internal pattern and optional generation.

Use air as a Channel Rack instrument. Image-Line's [official plug-in installation guide](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/basics_externalplugins.htm) covers scanning, verification and finding newly installed instruments.
