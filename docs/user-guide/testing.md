# Help test the alpha

You do not need to write code. Use a copy of a project, keep your saved work and start at a comfortable monitoring level. Read [what this alpha means](alpha.md) before testing.

## One useful first session

1. Keep the exact download filename and version. [Check its download](checksums.md), then follow [installation](install.md).
2. Use the [first-session guide](getting-started.md) to hear a sound without an account. Note anything you had to guess or ask someone to explain.
3. Change a control, use Undo/Redo and save a sound. Load it again. Save and reopen the project too; note whether the sound and notes return as expected.
4. Try External MIDI from a clip/controller, then an Internal Pattern. Record which music program, sample rate and buffer setting you used.
5. If you already have several instances in your project, check that editing one leaves the others alone. Optional generation is a separate test; it is not needed to finish this session.

Stop if playback becomes unexpectedly loud or unstable. Save a copy before trying to reproduce a failure. A failure is useful feedback; there is no need to repeat it until you get a pass.

## Tell us what happened

Use **ALPHA → Copy report** or **Save to Desktop**, review the contents and share through your existing testing conversation. If you cannot open air, send the download version, music-program/Windows versions, the steps and error text instead. The feedback webpage is not ready yet. [Help](../SUPPORT.md) explains safe attachments and the future public issue route.

Say what you expected, what actually happened and whether you can repeat it. Include a report ID if you have one. A short original sound or MIDI file is more useful than a complete private project. Do not send account folders, someone else's recordings or material you cannot distribute.

After the session, answer: did you get a sound, in which music program, what stopped you, what did you make, and what should improve first? Tell us whether you used the guides alone or had help. There is no response deadline or guaranteed fix date.
