# air in Ableton Live on Windows

[Install air](install.md), then open Live. This is setup guidance; human testing of the air alpha in Live remains unfinished.

1. Open **Preferences → Plug-Ins → Plug-In Sources** and enable **Use VST3 Plug-In System Folder**. The installer uses the shared Windows VST3 folder. Let Live scan.
2. In Live's Browser, open **Plug-Ins** and search for **air**. Drag its VST3 instrument onto a MIDI track.
3. Open air, press **Start with a sound** if empty, and choose **External MIDI**.
4. Play a MIDI clip on that track, or arm the track and play your configured MIDI controller. Check the track's output and monitoring if it is silent.
5. Save the Live Set. [First session](getting-started.md) covers sound files, patterns and optional generation.

If air is missing, check the system-folder setting and rescan rather than making duplicate copies. See Ableton's [official Windows plug-in guide](https://help.ableton.com/hc/en-us/articles/209071729-Using-VST-plug-ins-on-Windows) for host-specific scanning help.
