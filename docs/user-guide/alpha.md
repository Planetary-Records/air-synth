# What this alpha means

air is an early **alpha, before beta**. It is ready for careful testing, with unfinished areas and possible bugs. Use copies of projects, keep backups of saved sounds and expect changes between versions.

## What you can try

Build a sound with the included synths and effects, play MIDI, write an internal pattern and save your work. You can make a drum kit with your own samples. These activities work without an account or an extra rack download. Start with [first session](getting-started.md).

Optional sound generation is experimental. It may be unavailable for an account even after browser consent; manual sounds remain usable. Inspect and audition proposed changes before applying them.

## What is still being checked

The current package is Windows x64 VST3. Automated Windows installation and sound checks have passed their recorded scope. Human testing in Ableton Live, Reaper and FL Studio is unfinished; the host guides are setup instructions, not compatibility certification. The unsigned installer's warning screens still need checking on a protected machine.

The next candidate includes twelve starter sounds in **BROWSE**; the extra rack library is still being prepared. The feedback webpage is unfinished. A qualified public download is not available from this source candidate yet. These guides include changes being prepared for the next candidate, so follow the guide bundled with your particular download.

## Help shape the next version

After a first session, tell us: did you get a sound, which music program did you use, what stopped you, what did you make, and what should improve first? Use the **ALPHA** badge to prepare a report, or follow [help and participation](../SUPPORT.md). Review anything you share and keep private projects and account data out of attachments.

No release date, response time or long-term compatibility is promised during this testing stage.
