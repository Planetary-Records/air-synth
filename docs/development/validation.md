# Validation scope

A build proves compilation, not a first sound, musical quality or host compatibility. The supported source path is the probes-off product and three functional checks in [building](building.md). Private historical numerical campaigns are not reproducible from this source selection; their missing inputs are not synthetic acceptance.

The actual VST3 can be qualified through [alpha smoke](alpha-smoke.md): validator, load/recall/render comparisons, rate/buffer matrix, ten simultaneous instances and one hour. Keep exact input hashes and first-attempt receipts. That paced functional host does not establish a general real-time deadline, memory bound, all-DAW compatibility or human listening result.

`RackSynthRender --factory-sounds --plugin ABS_BUNDLE --output ABS_FRESH_WORKSPACE_FOLDER` exports the twelve original starter sounds and listening WAVs through the actual VST3, asserting audio and recall. Run it through the native coordinator on a private desktop. Use fresh outputs and a complete staged bundle with its matching helper.

Clean protected-machine install/upgrade/uninstall, human DAW checklists, new-person guide validation and owner listening remain separate release checks. Unsigned warnings and account eligibility must be described from actual observations. Do not infer them from automated success.
