# Research methods and limits

The source includes original native implementations, test signals, behavioral tests and compatibility
fixtures. Raw reference-code/decompiler records, private CI logs and personal acceptance packets are not
part of this snapshot. Their omission does not establish independent implementation of every algorithm.

For work informed by another instrument, formulate a bounded question: control range/units, an envelope
or drift response, filter slopes, delay timing, wet/dry gain, decay behavior or state/host integration.
Use lawful access to the reference, preserve its identity/settings and separate observations from
hypotheses. Do not infer equations or general parity from a few traces. Share original methods and cleared
measurements; do not submit proprietary code, manuals, UI artwork or recordings without permission.

The project renderer and tests use deterministic notes, impulses and controlled states. Record the exact
source, rate, block geometry, quality, parameters and workload. Keep numerical checks, actual hosted
behavior, performance, UI acceptance and listening separate. Failed checks are useful; do not change
budgets or repeat expensive measurements merely to obtain a pass.

The optional tools/native/ReferencePluginProbe.cpp is development source, not a reference-plugin dependency
of the product. Native source/build/test and account-free manual playback do not require commercial
reference software. No reference-plugin or model-service request was run for this source preparation.
