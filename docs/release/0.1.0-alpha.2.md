# air 0.1.0-alpha.2

An early **alpha, before beta**, for Windows 64-bit VST3. Expect bugs and possible crashes. Try it in a spare project, save often and keep backups.

## What is new

- Twelve original starting sounds in BROWSE: Soft Pluck, Round Bass, Hollow Bass, Paper Keys, Slow Glow, Gentle Lead, Clear Bell, Bright Steps, Wide Chord, Velvet Pad, Glass Pulse and Dusk Brass. Play and edit them offline without an account or extra downloads.
- First SAVE opens a dialog for your own sound file. Saving your DAW project also keeps the phrase and playback mode.
- Improved account switching and recovery after an unfinished sign-in. The built-in GPT feature remains experimental; this alpha supports a paid ChatGPT subscription, with continuing account permissions and usage limits.
- Improved guidance when a proposed sound changes its level. Inspect and audition changes before Apply; use Undo to compare.
- Safer updates when a helper is idle, while preserving active clients and user files.
- An illustrated [producer manual](https://air.planetary.music/manual) covers first sound, saving, sign-in, feedback, connecting a local assistant through MCP, making racks with a skill and preparing library contributions.

## Download and install

Use the `.exe` Windows installer attached to this release. The main Download button on the [air page](https://air.planetary.music/) uses that same versioned file. The manual ZIP is an alternative; it is not the installer. Check the matching SHA256 before running either download. The alpha is unsigned; Windows may show a warning. Do not disable your protection to install it.

Save your project and close music programs using air before updating. Install normally; Windows may request permission. Keep the entire installed folder together. The instrument is listed as air and may be grouped under AI Rack Synth. Existing compatibility IDs and legacy bundle filenames are preserved. See the included install guide.

## Known limits

- This is an early alpha, with limited host testing. Reaper, Ableton Live and FL Studio guide instructions are not a promise of human verification in every version. Windows 11 has automated clean-guest installation coverage; protected-machine warning behaviour and other Windows versions remain unverified.
- Built-in sound requests need a compatible paid ChatGPT account for this alpha. Permission or usage limits can still prevent a request. Manual controls and starting sounds work without sign-in; an external assistant can use local MCP with its own account and usage rules.
- Optional rack downloads and community submissions depend on the library being publicly available. The twelve starting sounds do not depend on it.
- Higher quality settings can add latency and processing cost. Check levels, keep backups and avoid relying on an alpha as the only copy of important work. Compatibility between future alphas is not guaranteed.
- Reports are reviewed as time permits; there is no support response deadline. The instrument does not send reports automatically.

## Feedback

Click the ALPHA badge to prepare a report. Review it, then copy or save it and send it through the [feedback page](https://air.planetary.music/feedback). Include the version, music program, what you expected and steps to repeat the problem. Your email is optional. Remove private paths, account details and material you cannot share. If installation or loading fails, use the webpage without an in-app report.
