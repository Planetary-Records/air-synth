# air

air is a free instrument for playable sounds, drum kits and editable patterns in a Windows music program, developed by Planetary. This is an early **alpha, before beta**. Use copies of projects and save often.

Manual sounds, MIDI and saved kits work offline without an account. Start with the included synths and effects, choose one of twelve starter sounds from BROWSE, or build a kit with your own samples. For built-in GPT requests this alpha supports a paid ChatGPT subscription; account permission and usage limits still apply. Local MCP control by an external assistant is separate from air sign-in.

## Try it

The target is Windows x64 with a VST3-capable music program. There are no Mac, Linux or ARM packages. Shipping alpha builds need no separate runtime installation. Use the [air download page](https://air.planetary.music/) for the matching `0.1.0-alpha.2` Windows installer attached to GitHub Releases. The same release includes the manual ZIP, source and checksums. See the [illustrated manual](https://air.planetary.music/manual) and [release notes](docs/release/0.1.0-alpha.2.md).

Follow [installation](docs/user-guide/install.md), [first session](docs/user-guide/getting-started.md), [host setup](docs/user-guide/vst3.md) and [troubleshooting](docs/user-guide/faq.md). [Alpha status](docs/user-guide/alpha.md) explains what remains under test. The installed folder keeps the older name AI Rack Synth.vst3 while the instrument appears as air.

Save the DAW project for the complete sound, notes and mode. Save a sound file to reuse its sound elsewhere. Inspect and audition a generated proposal before Apply. Keep backups before updates.
